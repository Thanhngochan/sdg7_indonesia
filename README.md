# No Carbon Footprint in Indonesia — is it possible?

A React (Vite) website about SDG 7: Affordable and Clean Energy, built from the infographic.

## Run it in VS Code

1. Install Node.js 18 or newer (https://nodejs.org).
2. Open this folder in VS Code: File > Open Folder.
3. Open the terminal (Terminal > New Terminal) and run:

   ```
   npm install
   npm run dev
   ```

4. Open the link it prints (http://localhost:5173).

`npm run build` creates the final site in `dist/`, ready to upload to GitHub Pages, Netlify or Vercel.

## Where things are

- `src/data.js` — every number, table row and reference. Edit text here.
- `src/components/` — one file per section of the page.
- `src/styles.css` — colours (at the top, under `:root`) and layout.
